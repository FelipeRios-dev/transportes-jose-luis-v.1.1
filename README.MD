TRANSPORTES JOSÉ LUIS — LANDING PAGE
======================================

ESTRUCTURA
----------
index.html              Página principal
css/styles.css          Estilos y diseño adaptable
js/script.js             Menú móvil y formulario de cotización
assets/                  Fotografías e imágenes del camión

CÓMO PROBAR
-----------
1. Descomprime el archivo ZIP.
2. Abre la carpeta "transportes-jose-luis".
3. Abre index.html en Chrome, Edge o Firefox.
4. Para desarrollo, puedes abrir la carpeta en Visual Studio Code.

CONTENIDO Y DATOS
-----------------
- Operación base: Jamundí y Cali, Valle del Cauca.
- Se menciona servicio nacional sujeto a ruta, tipo de carga y disponibilidad.
- Vehículo: Chevrolet NKR.
- Capacidad máxima indicada por el propietario: 3.500 kg. Verificar siempre
  la capacidad legal/técnica aplicable y las condiciones de la carga.
- José Luis: más de 10 años de experiencia al volante.
